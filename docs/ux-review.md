# Проверка кадрового интерфейса

Главная и генерация документов — расширения внутри SuiteCRM. Карточки, CRUD, связи и права использовали штатный интерфейс. Проверены кадровые модули и инструкции SuiteCRM Record Management / Studio. Ядро и Angular не изменяются.

| Проблема | Изменение |
|---|---|
| Пустые торговые разделы | Кадровая навигация пользователей |
| Длинная карточка | Группы: личные данные, служба, контракт, сведения |
| Случайные первые колонки | Явные колонки сотрудников, связанных записей и аудита |
| Нет образцов | Инструкции и вымышленные примеры по каждому блоку |
| Сброс формы | Черновик по пользователю и сотруднику, точные ошибки |
| Дубли при обновлении | POST → 303 → GET |
| Неясное состояние отправки | Кнопка формирования и защита от двойного клика |
| История без порядка | Дата, автор, версия; новые документы первыми |
| Сложный аудит | Русские операции и таблица «было / стало» |
| Нет каталога шаблонов | Каталог, создание копии администратором и редактор |

Паттерны: постоянная навигация, одно главное действие, группировка полей, подсказки рядом с задачей, раскрытие необязательных параметров, ошибки рядом с полями, пустые состояния, ограничения роли, адаптивная сетка и видимый фокус клавиатуры.

Обновлены кадровые сценарии демо. Другие модули CRM для продаж и почты не переделывались. Шаблоны создаются как копии поддерживаемых форм; новые вычисления требуют настройки генератора. Черновик сохраняется в текущей сессии после отправки. PDF после ручных правок DOCX не обновляется.

Источники:
- https://docs.suitecrm.com/8.x/user/core-concepts/record-management/
- https://docs.suitecrm.com/8.x/user/core-concepts/views/
- https://docs.suitecrm.com/admin/administration-panel/studio/


Кадровые разделы зарегистрированы в системных вкладках SuiteCRM. Документы, шаблоны и инструкции представлены навигационными модулями, открывающими существующие защищённые страницы. Пользовательские предпочтения явно сохраняются в БД. В списке сотрудников добавлены основная кнопка создания и ссылка на пример. Проверены вкладки трёх ролей и переход к документам из штатного меню.
