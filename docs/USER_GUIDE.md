# Руководство кадровика

## Где находятся разделы

После входа откройте главную страницу: это рабочее место с переходами к сотрудникам, документам, шаблонам, аудиту и инструкциям. Кадровые разделы также есть в меню CRM. На узком экране часть пунктов может находиться в раскрывающемся меню.

CRM хранит карточки и связанные записи. Дополнительные кадровые страницы написаны внутри интеграции с SuiteCRM; ONLYOFFICE открывается для работы с документами. Отдельный сайт устанавливать не требуется.

## Создать сотрудника

1. Откройте «Сотрудники» → «Создать сотрудника» над списком.
2. Введите ФИО. Добавьте личный номер, звание, должность, подразделение и остальные сведения.
3. В поле «Руководитель» выберите существующего сотрудника. Если руководителя ещё нет, сначала создайте его карточку.
4. Нажмите «Сохранить / Save». Для исправления откройте карточку → «Редактировать / Edit».

Образец для ручного ввода:

| Поле | Пример |
|---|---|
| ФИО | Петров Дмитрий Сергеевич |
| Личный номер | ДЕМО-004 |
| Дата рождения | 15.03.1994 |
| Звание | Капитан |
| Должность | Начальник отделения |
| Подразделение | Учебный отдел |
| Руководитель | Соколов Алексей Петрович |

Карточка сотрудника не даёт ему доступ в CRM. Учётные записи создаёт администратор через «Администрирование → Пользователи» с назначением роли. Длинный ID в адресной строке — технический идентификатор записи; для работы используйте ФИО и личный номер.

## Добавить родственника, образование, награду или службу

1. Откройте карточку человека и вкладку «Связи / Relationships».
2. Найдите нужный блок: родственники, образование, награды или служба. Нажмите «Создать».
3. Заполните сведения и сохраните. При создании через общий список раздела обязательно выберите сотрудника.
4. Вернитесь в карточку и проверьте появление записи в соответствующем блоке.

| Вид записи | Образец |
|---|---|
| Родственник | Петрова Анна Викторовна; супруга; дата рождения 20.07.1995 |
| Образование | Учебная академия; инженер; 01.09.2012–30.06.2017 |
| Награда | «За отличие в службе»; 12.05.2025; приказ № 125 от 12.05.2025 |
| Служба | Учебный центр; инструктор; 01.09.2020–31.12.2024 |

Каждая награда, родственник и период — отдельная запись. Для текущего места службы оставьте дату окончания пустой: документ покажет «по настоящее время». Изменять запись можно, открыв её название в блоке связей.

Удаление доступно в действиях карточки. Удаление сотрудника скрывает также его связанные записи; события остаются в аудите. Не используйте удаление для временного исправления данных.

## Создать документ на одного человека

1. На главной выберите человека и откройте «Документы» либо нажмите «Сформировать документ» в карточке.
2. Выберите шаблон: рапорт на отпуск, список наград или послужной список.
3. Для наград и службы данные подставятся из связанных записей CRM. Для рапорта заполните начало и окончание отпуска.
4. Раскройте дополнительные поля рапорта: адресат, причина, место, транспорт, возвращение, согласующие. ФИО в дательном падеже при необходимости задаётся вручную.
5. Нажмите «Сформировать документ». При ошибке исправьте указанное поле и повторите отправку — заново вводить всю форму в текущей сессии не требуется.
6. Скачайте DOCX/PDF или откройте документ в ONLYOFFICE. Результат также доступен в истории документов сотрудника.

Пример: ежегодный отпуск с 01.11.2026 по 14.11.2026, место — Санкт-Петербург, транспорт — железнодорожный. Дни считаются включительно, в примере 14 дней.

Повторная генерация создаёт новый результат. Обновление страницы результата не отправляет форму повторно. Правки карточки не меняют старые документы. Редактор сохраняет изменения в DOCX; PDF остаётся результатом первоначальной генерации. Для обновлённого PDF потребуется отдельная конвертация или новая генерация с нужными данными.

## Создать одинаковый документ нескольким людям

1. Откройте «Документы» → «Создать документы для нескольких сотрудников».
2. Отметьте до 20 человек и выберите шаблон.
3. Укажите общие параметры, например одинаковые даты отпуска. Не вписывайте ФИО одного заявителя в общие поля: сведения каждого человека берутся из его карточки.
4. Нажмите «Сформировать документы».
5. Скачайте отдельные DOCX/PDF или общий ZIP. При ошибке одного документа остальные результаты сохраняются; проверьте сообщения по каждому человеку.

Для следующего комплекта нажмите «Сформировать новый пакет». Документы появляются в индивидуальной истории сотрудников, генерация записывается в аудит.

## Изменить или создать шаблон

Этот раздел доступен для изменения администратору.

1. Откройте «Шаблоны».
2. Задайте название и выберите основу: рапорт, награды или служба. Нажмите «Создать копию».
3. Откройте копию в ONLYOFFICE, измените текст и оформление. Сохраните заполняемые блоки и их теги.
4. Сохраните шаблон, закройте редактор и сделайте пробную генерацию на сотрудника.

Подстановка работает через элементы управления содержимым Word (content controls), по их тегам. Например, `person.position` — должность, `person.department` — подразделение; блоки `awards` и `service` используются для составных данных, `leave.*` — для параметров рапорта. Полный набор зависит от основы шаблона.

Просто написать `{{ФИО}}` в тексте недостаточно. Произвольный загруженный DOCX не становится рабочим шаблоном автоматически. Новый вид таблицы, вычисление или источник данных требует изменения генератора. Начинайте с копии поддерживаемого шаблона и проверяйте результат до использования.

## Посмотреть, кто изменил данные

Откройте «Аудит». Событие содержит автора (имя и логин), время, операцию и значения «Было / Стало». Отфильтруйте журнал по автору, разделу или операции; «Вся история этой записи» открывает историю конкретной записи.

Журнал отражает действия, которые интеграция записала: создание, изменение, удаление, связи и генерацию документов. Ранее не записанные события восстановить нельзя. Прямые изменения SQL вне приложения не отслеживаются этими обработчиками; администратор базы имеет доступ к самому журналу. В демо также могут присутствовать события проверок.

## Оформление, выход и роли

Настройки темы, цвета и плотности открываются по значку оформления. По умолчанию тема светлая; выбор запоминается в браузере. Кнопка «Выйти» справа сверху завершает сессию, на узком экране она может отображаться значком.

| Вход | Возможности |
|---|---|
| hr_editor | Карточки и связанные данные, генерация и редактирование документов |
| hr_viewer | Просмотр карточек, готовых документов и аудита |
| admin | Возможности кадровика, настройка CRM и шаблоны |

Инструкции с образцами доступны и внутри приложения в разделе «Инструкции». Для установки и восстановления запуска смотрите [руководство по установке](INSTALL.md).
