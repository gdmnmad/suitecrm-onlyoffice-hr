# Источник экспериментальной сборки

https://github.com/aleho/onlyoffice-ce-docker-license
Commit: 16c54c0fcea8318db7cc28fd044fcc20294fa729

Dockerfile и два патча сохранены из этого репозитория. Базовый ONLYOFFICE: 6.3.1.32, архитектура amd64. Это отдельный экспериментальный override. Официальный актуальный образ в compose.yaml не заменён.

Готовый образ alehoho/oo-ce-docker-license недоступен при проверке Docker Hub. Проверяется сборка из исходников. Патч не изменяет отдельный SDK Document Builder.

Локальная корректировка: `make` заменён на `make build-date`. Полная цель пытается копировать отсутствующий `schema/**`; финальный образ берёт штатные schema/ресурсы из того же базового образа, а из сборки копируются только изменённые бинарники и mobile JS.

После проверок сборки: npm обновлён до 7.24.2 (Node 10 совместимый), проверки целостности сохранены; повторная сборка SpellChecker исключена, он остаётся штатным. Применяется серверная часть патча. Архивная сборка мобильного интерфейса не прошла grunt, мобильные файлы оставлены из базового образа. Неиспользуемый Lua-модуль nginx отключён для запуска на Apple Silicon через amd64-эмуляцию.

В упаковку pkg явно включены исходники Common/DocService/FileConverter, включая динамически выбираемые коннекторы БД. Без этого DocService не находил postgreSqlBaseConnector при старте.
